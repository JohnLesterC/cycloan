## 📝 How to Use

### Step 1: Review Documents
```
1. Open loan details modal
2. Review each document
3. Click APPROVE or REJECT
4. Email sent automatically with:
   • Document status changed ✓
   • Your name ✓
   • Current time ✓
   • All other documents' status ✓
```

### Step 2: Add Notes (Optional)
```
1. Scroll to "Decision Notes" section
2. Type your remarks (max 500 chars)
3. Your name auto-fills
4. Decision notes added to email
```

### Step 3: Make Final Decision
```
1. Select status:
   ○ Keep Pending
   ○ Approve (requires notes)
   ○ Reject (requires notes)
2. Notes required for Approve/Reject
3. Click "Submit Decision"
4. Final email sent with EVERYTHING
```

## 💡 Tips

1. **Add Good Notes**
   - "All clear ✓" vs "Applicant shows stable income with 5+ year employment history and excellent bank records. No red flags."
   - Second one is better for records

2. **Check Documents First**
   - Approve/reject each before final decision
   - This ensures email has all details

3. **Watch for Status Lock**
   - Can only APPROVE if ALL docs are approved
   - Otherwise "Approve" button is disabled
   - Ensures consistency

4. **Notes are Required**
   - Approve status → Must add notes
   - Reject status → Must add notes
   - Pending status → Optional
   - Ensures good documentation

## ❓ FAQ

**Q: Will applicant receive multiple emails?**
A: No! One consolidated email per major update with complete information.

**Q: Is my name always tracked?**
A: Yes! Your name appears automatically from your admin account.

**Q: Can I see who made previous changes?**
A: Yes! Check the Remarks History section - shows admin name for each remark.

**Q: What if I need to add more notes later?**
A: Add another remark - it will appear in history with your name and timestamp.

**Q: Will old emails show admin names?**
A: New emails will. Old emails won't have it (system just updated).
