## 🚨 QUICK TROUBLESHOOTING

| Issue | Quick Fix |
|-------|-----------|
| Server won't start | Check port 8000 not in use, restart PHP |
| Can't login | Verify email/password, check DB connection |
| Page slow | Close other tabs, clear cache, restart browser |
| Data missing | Import database SQL file, verify tables exist |
| Email not working | Verify PHPMailer config, can skip for demo |
| Display broken | Clear cache, zoom to 100%, try incognito |
| Session timeout | Login again, keep active during demo |

## 📱 REAL-TIME EMAIL VALIDATION - DEMO STEP

**This is THE standout feature - demonstrate it well:**

1. Go to registration.php, Step 2
2. Point out email field
3. Slowly type: `j.` → wait → `j.d` → wait → `j.delacruz@email.com`
4. Show the **green checkmark appear**
5. Say: "This happens in real-time! The system checks our database as you type. If the email exists, it shows red. This prevents duplicate accounts instantly."

7. Say: "This saves everyone time - no more 'email already registered' errors after filling out the whole form!"

**Why This Works**: Visual, immediate, solves real problem
